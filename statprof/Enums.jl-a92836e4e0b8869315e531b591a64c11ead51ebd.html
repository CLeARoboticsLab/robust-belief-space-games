78 # generate code to test whether expr is in the given set of values
79 function membershiptest(expr, values)
80 lo, hi = extrema(values)
81 if length(values) == hi - lo + 1
82 :($lo <= $expr <= $hi)
83 elseif length(values) < 20
84 foldl((x1,x2)->:($x1 || ($expr == $x2)), values[2:end]; init=:($expr == $(values[1])))
85 else
86 :($expr in $(Set(values)))
87 end

95 """
96 @enum EnumName[::BaseType] value1[=x] value2[=y]
97
98 Create an `Enum{BaseType}` subtype with name `EnumName` and enum member values of
99 `value1` and `value2` with optional assigned values of `x` and `y`, respectively.
100 `EnumName` can be used just like other types and enum member values as regular values, such as
101
102 # Examples
103 ```jldoctest fruitenum
104 julia> @enum Fruit apple=1 orange=2 kiwi=3
105
106 julia> f(x::Fruit) = "I'm a Fruit with value: \$(Int(x))"
107 f (generic function with 1 method)
108
109 julia> f(apple)
110 "I'm a Fruit with value: 1"
111
112 julia> Fruit(1)
113 apple::Fruit = 1
114 ```
115
116 Values can also be specified inside a `begin` block, e.g.
117
118 ```julia
119 @enum EnumName begin
120 value1
121 value2
122 end
123 ```
124
125 `BaseType`, which defaults to [`Int32`](@ref), must be a primitive subtype of `Integer`.
126 Member values can be converted between the enum type and `BaseType`. `read` and `write`
127 perform these conversions automatically. In case the enum is created with a non-default
128 `BaseType`, `Integer(value1)` will return the integer `value1` with the type `BaseType`.
129
130 To list all the instances of an enum use `instances`, e.g.
131
132 ```jldoctest fruitenum
133 julia> instances(Fruit)
134 (apple, orange, kiwi)
135 ```
136
137 It is possible to construct a symbol from an enum instance:
138
139 ```jldoctest fruitenum
140 julia> Symbol(apple)
141 :apple
142 ```

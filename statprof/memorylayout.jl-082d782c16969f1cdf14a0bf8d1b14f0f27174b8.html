33 """
34 AbstractStridedLayout
35
36 is an abstract type whose subtypes are returned by `MemoryLayout(A)`
37 if an array `A` has storage laid out at regular offsets in memory,
38 and which can therefore be passed to external C and Fortran functions expecting
39 this memory layout.
40
41 Julia's internal linear algebra machinery will automatically (and invisibly)
42 dispatch to BLAS and LAPACK routines if the memory layout is BLAS compatible and
43 the element type is a `Float32`, `Float64`, `ComplexF32`, or `ComplexF64`.
44 In this case, one must implement the strided array interface, which requires
45 overrides of `strides(A::MyMatrix)` and `unknown_convert(::Type{Ptr{T}}, A::MyMatrix)`.

316
